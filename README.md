# 📸 JCVcreatives / Gobble Haus Photobooth Kiosk

Offline-ready Photobooth Kiosk for Android tablets (Android 7.0 Nougat through Android 14+) and Web PWA with Bluetooth/USB/Wi-Fi thermal receipt printing, numeric voucher codes, custom frames, and HD Offline QR photo transfer.

---

## 📲 Download Android `.APK` (v2.6.0)

Every push to `main` automatically builds and signs the standalone offline Android APK (`JCVcreatives-Photobooth.apk`) via GitHub Actions.

### Option 1: Direct Download from GitHub Releases (Recommended)
👉 **[Download JCVcreatives-Photobooth.apk (Latest Release)](../../releases/latest/download/JCVcreatives-Photobooth.apk)**
*(Or click **Releases** in the right sidebar of this GitHub repository and tap `JCVcreatives-Photobooth.apk`)*

### Option 2: Direct Download from GitHub Pages
👉 **[https://jcvcreatives.github.io/photobooth/JCVcreatives-Photobooth.apk](https://jcvcreatives.github.io/photobooth/JCVcreatives-Photobooth.apk)**

### Option 3: Download from GitHub Actions Build Artifacts
1. Open the **[Actions](../../actions)** tab at the top of this GitHub repository.
2. Click the latest **Build APK & Deploy to GitHub Pages** workflow run.
3. Scroll down to **Artifacts** and click **`JCVcreatives-Photobooth-APK`**.
